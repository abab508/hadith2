# Fiche : veille marché
1. Définis le sujet en une phrase (ex. « logiciels de gestion d'exploitation agricole en France »).
2. Trouve 5 à 8 concurrents. Pour chacun : offre, prix public, cible, point fort, point faible, lien.
3. Repère 3 tendances, chacune avec 2 sources datées.
4. Conclus par 3 enseignements pour l'agence (où se placer, quel prix, quel manque à combler).
5. Pas de source = pas d'affirmation. Chiffres de bourse ou de vidéos : vérifier sur une 2e source.
