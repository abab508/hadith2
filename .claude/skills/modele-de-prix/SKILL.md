# Fiche : modèle de prix
1. Plancher : jamais sous le coût de revient (fiche cout-de-revient) + la marge voulue par le patron.
2. Prestation : prix au jour (TJM) ou forfait. Le forfait se vend mieux s'il est clairement délimité.
3. SaaS : facturer ce qui crée de la valeur pour le client (par exploitation, hectare, élève, projet…), pas forcément par utilisateur.
   Le modèle par siège est menacé là où des agents IA remplacent des utilisateurs.
4. Modèle hybride conseillé : abonnement de base + part à l'usage (crédits IA, volume).
5. Fonctions IA : chaque appel coûte. Les inclure en crédits limités, supplément au-delà, pour protéger la marge.
6. Compare avec docs/strategie/veille-*.md. Propose 3 paliers max (ex. découverte / pro / entreprise).
