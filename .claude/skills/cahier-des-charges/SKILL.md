# Fiche : cahier des charges
Dans docs/projet/cahier-des-charges.md :
1. Objectif : le problème en une phrase.
2. Utilisateurs : qui va s'en servir.
3. Fonctionnalités : liste numérotée, chacune avec « réussi quand… » vérifiable.
4. Hors périmètre : ce qu'on ne fait pas dans cette version.
5. Contraintes : langues, appareils, hébergement, délais.
6. Questions ouvertes : tout ce qui n'est pas clair (en autopilote : choix le plus simple, noté dans decisions.md).
