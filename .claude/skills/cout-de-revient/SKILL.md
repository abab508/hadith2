# Fiche : coût de revient
Données : docs/strategie/couts.md uniquement. Case vide = la signaler, ne jamais l'inventer.
1. Coûts fixes par mois : logiciels et abonnements IA, matériel (amorti), assurance, comptable, local, rémunération voulue du patron + charges.
2. Jours vraiment facturables par mois : jours travaillés × taux d'occupation (souvent 50 à 70 % au début : prospection, admin, formation).
3. Coût de revient d'un jour = coûts fixes mensuels ÷ jours facturables.
4. Coût d'un projet = jours estimés × coût d'un jour + coûts spécifiques (licences, API IA consommées, hébergement).
5. Montre chaque calcul ligne par ligne. Résultat dans docs/strategie/prix.md.
