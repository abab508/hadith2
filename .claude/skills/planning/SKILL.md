# Fiche : planning
1. Lis la demande (et docs/projet/cahier-des-charges.md s'il existe).
2. Découpe en tâches de moins d'une heure. Une tâche = un résultat visible et vérifiable.
3. Ordonne : ce qui bloque les autres d'abord.
4. Écris dans docs/memoire/taches.md, une ligne par tâche : `- [ ] verbe + quoi + où`.
   Exemple : `- [ ] Ajouter la page météo avec les prévisions sur 7 jours`
   Tâche business : `- [ ] [strategie] Calculer le coût de revient d'une journée de travail`
5. Pas plus de 10 tâches à la fois : au-delà, garde le reste dans une section « Plus tard ».
