# Fiche : idées produit
1. Sources : retours utilisateurs, veille, journal, tâches [!] récurrentes.
2. Pour chaque idée : problème résolu, pour qui, impact (1-5), effort (1-5).
3. Score = impact ÷ effort. Classe par score.
4. Écris le tableau dans docs/strategie/idees.md.
5. Propose les 3 meilleures au patron (taches.md, marquées « - [!] à valider : ... »).
